КОНСТРУКТОР ЩИТА — ИНТЕРКАБЕЛЬ. Этап 1 рефакторинга.

В папке теперь 4 файла (раньше был один):
  index.html   — страница приложения (была частью старого файла)
  styles.css   — все стили
  catalog.js   — прайс, 2339 позиций
  app.js       — логика приложения

КАК ОБНОВИТЬ НА GITHUB:
1. Откройте свой репозиторий → Add file → Upload files.
2. Перетащите ВСЕ ЧЕТЫРЕ файла сразу (index.html, styles.css, catalog.js, app.js).
3. Важно: старый большой HTML-файл с прежним именем удалите из репозитория
   (откройте его → значок корзины → Commit changes), чтобы не осталось двух версий.
4. Commit changes. Обновите страницу сайта — должно заработать.

КАК ПРОВЕРИТЬ ЛОКАЛЬНО:
Распакуйте архив в одну папку и откройте index.html двойным кликом.
Все четыре файла должны лежать рядом.

Проекты (сохранения) не пострадали: они хранятся в браузере отдельно.
Если что-то не так — внизу экрана появится красная строка с текстом ошибки;
пришлите её скриншот.
